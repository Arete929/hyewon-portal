# 과목별 머리 이미지

관리자 «설정 → 교사 정보»에서 고른 과목과 같은 이름의 이미지가 있으면 관리자·학생 화면 머리(사이드바·휴대폰 머리·학생 로그인·오늘의 과제)에 써요. 없으면 기본 이미지(`../login-bg.webp`)를 써요.

- 파일 이름: `과목.webp` (또는 `과목.jpg`) — 예: `체육.webp`, `음악.webp`, `기술·가정.webp`
- 크기: 1600×900 (16:9), 300KB 안팎
- 얼굴·동작 같은 중요한 부분: 가로 15~75%, 세로 위쪽 10~50%
- 왼쪽 아래는 단순하게(제목·이름 글자가 덮여요), 이미지 안에 글자는 넣지 않기
